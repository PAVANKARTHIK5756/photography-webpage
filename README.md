Photography Portfolio WebsiteDescription:
This repository contains a clean, static photography portfolio webpage designed for "Pavan Karthik," built entirely with pure HTML and vanilla CSS. A standout feature of this project is the interactive, collapsible sidebar menu that utilizes a CSS-only checkbox hack for its toggle functionality, removing the need for JavaScript.  Features:CSS-Only Sidebar Navigation: A fully functional slide-out menu toggled via a hidden checkbox and a hamburger icon.  Comprehensive Menu Options: Includes organized navigation links for Gallery, Shortcuts, Exhibits, Events, Store, Contact, and Feedback.  Modern Typography & Icons: Utilizes the "Poppins" font family from Google Fonts and scalable vector icons from Font Awesome (v6.4.0) to create a sleek UI.  Social Media Integration: Features a dedicated section for social links, including Facebook, Twitter, Instagram, and YouTube.

Tech Stack:
HTML5: Semantic markup and layout structure.  CSS3: Custom styling and responsive menu mechanics linked via an external style.css file.  

How to Run:
Simply clone the repository and open index.html in your web browser. Ensure that your style.css file is located in the same root directory so the styling and sidebar mechanics render properly.
